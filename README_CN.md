## 技术方向

- **AI 与 RAG：** Python、LangGraph、LangChain、混合检索、重排与证据评测。
- **Web 应用：** FastAPI、React、SSE。
- **浏览器扩展：** JavaScript、Manifest V3、Service Worker、Web Crypto 与 IndexedDB。

求职方向以 AI 应用与 RAG 开发为主。
